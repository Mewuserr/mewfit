# MewFit

เทรนเนอร์ส่วนตัวที่บ้าน เว็บแอปไฟล์เดียว ใช้ได้ทันทีไม่ต้องสมัคร (ข้อมูลอยู่ในเครื่อง) หรือสร้างบัญชีด้วยชื่อผู้ใช้ + รหัส 6 หลัก เพื่อซิงก์ข้อมูลขึ้น Cloudflare D1 และใช้ได้หลายเครื่อง

- ตั้งค่า 8 ขั้น: คัดกรองสุขภาพ (PAR-Q+), ข้อมูลร่างกาย, เป้าหมาย, กิจกรรม, การฝึก, ทดสอบความฟิต, ตารางเวลา
- ตารางฝึกที่บ้านที่เลื่อนขั้นเอง 62 ท่า พร้อมภาพเคลื่อนไหวสาธิต
- แผนอาหารไทยตามแคลอรี่และโปรตีน, ตารางชีวิต, ติดตามน้ำหนักและสัดส่วน
- ตัวจับเวลาวอร์มอัพ ยืดเหยียด และวงจร 7 นาที

เว็บ: https://mewfit.m3wxuser.workers.dev

ข้อมูลในแอปเป็นข้อมูลทั่วไป ไม่ใช่คำแนะนำทางการแพทย์
